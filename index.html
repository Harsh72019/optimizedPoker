🧪 Private Table SNG Testing Guide

1. Create Private Table: Fill in host token, configure stakes (NO_LIMIT 5/10), timer (45s), players (2-6), buy-in (100-200), enable rebuy/antes as needed.
2. Register Players: Use different tokens to join the private table. Need minimum players based on your min setting.
3. Start Game: Host clicks "Start Game" when enough players joined.
4. Join Game: Players use "Join Game as Player A/B" buttons to join the actual poker game.
5. Test Features: Verify custom blinds (5/10), turn timer (45s), antes (if enabled), rebuy rules, stakes validation.
6. Monitor Events: Watch for privateGameStarted, antesPosted, privateTableTurnTimerStarted events.

Setup Fee Formula: 0.05 × (a × BuyIn) × (b × Capacity) × (c × Hours) - (d × SpeedBonus)
a = 1.2, b = 1.1, c = 1.05, d = 0.95
Example: BuyIn=100, Capacity=6, Hours=2, SpeedBonus=10
= 0.05 × (1.2 × 100) × (1.1 × 6) × (1.05 × 2) - (0.95 × 10)
= 0.05 × 120 × 6.6 × 2.1 - 9.5
= 83.16 - 9.5 = 73.66

• Stakes control actual betting rules (Fixed/Pot/No Limit)

• Antes posted automatically if enabled
